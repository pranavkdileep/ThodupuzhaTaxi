# Thodupuzha Taxi - Pazheri Cab Service Website

A modern, responsive website for Pazheri Cab Service, offering taxi bookings from Thodupuzha to all over Kerala.

## Features

- **Responsive Design**: Mobile-first design that works on all devices
- **Fleet Information**: Display of available vehicles (Hatchback, Sedan) with pricing
- **Direct Booking**: WhatsApp and phone call integration for instant bookings
- **Service Overview**: Complete list of services including airport transfers, temple tours, wedding trips
- **Modern UI**: Built with Next.js, Tailwind CSS, and shadcn/ui components

## Services Offered

- Airport Pickup/Drop (Cochin, Calicut)
- All Kerala Tour Packages
- Temple Tour Packages
- Wedding Trips
- Vehicle Rentals (Hatchback, Sedan, SUV)
- Tempo Traveller & Mini Bus

## Tech Stack

- **Framework**: Next.js 14+
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui
- **Icons**: Lucide React
- **Language**: TypeScript

## Getting Started

1. **Install dependencies**:
   ```bash
   pnpm install
   ```

2. **Run the development server**:
   ```bash
   pnpm dev
   ```

3. **Build for production**:
   ```bash
   pnpm build
   ```
